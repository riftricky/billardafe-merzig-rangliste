# Weiterleitung bestehender App-Links

Dieses Repository betreibt ausschließlich die Weiterleitung der bereits verteilten alten App-Adresse.

- Aktuelle App: https://riftricky.github.io/billardcafe-merzig-rangliste/
- Eigentliche App-Quellen: https://github.com/riftricky/billardcafe-merzig-rangliste

Der historische Name ist für diese alte Adresse technisch erforderlich. Dieses Repository enthält keine zweite App, keine Konten und keine Datenbank. Gültige Einladungs- und Partierouten bleiben beim Wechsel erhalten; URL-Abfragen und frühere Anmeldecodes werden nicht übertragen.

Lokale Git-Kopien der eigentlichen App sollten als Remote das korrekt benannte Repository verwenden. Die Weiterleitung ist für ältere App-Links und QR-Codes gedacht.
